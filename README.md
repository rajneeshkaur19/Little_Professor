# 🧮 Little Professor

> A mental math CLI game — 10 problems, 3 chances each.

![Python](https://img.shields.io/badge/Python-3.x-blue) ![No Dependencies](https://img.shields.io/badge/dependencies-none-brightgreen) ![CLI](https://img.shields.io/badge/type-CLI-lightgrey)

---

## 🎯 Difficulty Levels

| Level | Range |
|-------|-------|
| 1 — Beginner | 0 – 9 |
| 2 — Intermediate | 10 – 99 |
| 3 — Advanced | 100 – 999 |

---

## ⚙️ How It Works

- 10 random addition problems per round
- 3 attempts per question before the answer is revealed
- Wrong answer prints `EEE`
- Final score shown out of 10

---

## 🚀 Run It

```bash
python Little_Professor.py
```
